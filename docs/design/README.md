# Design records

`decisions.md` is the decision slate. Each record has a number, a date, the
decision, the reason, and what it rejects. A record binds the code; the code
follows the record or the record is amended by an explicit edit.

Per-milestone records arrive with their milestone, named `m1-surface.md`,
`m2-particles.md`, and so on. Open decisions live in `HANDOFF.md` until a
milestone decides them.
